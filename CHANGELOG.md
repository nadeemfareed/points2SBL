# Changelog

## 0.3.0

- pretrained-first minimal inference interface;
- `raw`, `full`, and `adaptive` inference modes;
- deterministic `grid8` and mixed `hybrid8` voting;
- adaptive empirical leaf-probability distribution diagnostics;
- transition-only geometry/local resolution;
- explicit pretrained model manager and SHA256 verification;
- packaged inference profiles with expert CLI overrides;
- public release cleanup and cloud/Colab documentation.
